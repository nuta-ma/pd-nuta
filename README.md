# pd-nuta

Pure Data abstractions and externals I frequently use

## Externs

**[conv~]** - overlap-save convolution  
**[morph~]** - M. Berge's algorithm for morphing audio  
**[hwt~]** / **[ihwt~]** - Haar wavelet transform and inverse  



## Abstractions

**[norph~]** - morphing algorithm based on granular with ultramicro grains  
**[rev5~]** - foggy reverb which sustains inputs infinitely unless later inputs interrupt  
**[zoom]** - oscilloscope with zoom
